# Travel Agency ER Diagram

This folder contains the exported entity-relationship diagram for a travel-agency database. The diagram is a visual description of the data structures and business relationships needed to organize travel-agency operations.

## PDF

- [Travel-Agency.pdf](Travel-Agency.pdf) - exported ER diagram

## What the Diagram Documents

The PDF shows the current conceptual database design, including:

- The main entities involved in the travel-agency domain
- Attributes that describe each entity
- Identifying attributes used to distinguish records
- Relationships between customers, travel offerings, bookings, and related agency data
- The structure needed to translate the conceptual model into relational tables

## How to Use It

Use the diagram to review the domain before implementing a database schema. Entity boxes represent the major data objects, attribute labels describe the information stored for each object, and relationship symbols show how records are connected. The model can be used to identify candidate primary keys, foreign keys, and relationship tables during the logical database-design stage.
